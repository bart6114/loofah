# Astra assignment and story structure

Use when the user wants a copyable prompt or when briefing a video build. Resolve fields from the request and current source; remove irrelevant sections. Preserve the requested model. This is a creative production assignment, not an API integration or a claim that Astra generates video by itself.

## Copyable assignment

```text
Use $loofah-launch-video to direct and produce a Loofah launch film.

Launch topic: [product or feature]
Audience and destination: [viewer and channel]
One takeaway: [one concrete benefit]
Length and format: [default 30 seconds, 1920×1080, 30 fps]
Available footage/assets: [paths, or discover in the Loofah checkout]
Audio: [licensed instrumental music by default; narration only if requested]
Output directory: [project/export location]

Read the skill's brand reference and verify relevant current product claims.
Choose a clear visual concept, write a timed shot list, and continue through
editable source, rendering, and inspection. Make routine creative decisions
and state assumptions briefly. Ask only about choices that materially alter
the brief or prevent completion. If I requested only a prompt or script,
deliver that stage without starting an unrequested video project.

Develop a distinctive visual idea using the skill's art-direction reference.
Build the film around a recurring form that transforms with the story, with
crafted typography, original illustration, and purposeful transitions. Keep
forest green, pale leaf accents, Fraunces, and canonical Loofah artwork as
identity anchors, while giving each scene an intentional composition.
Show a recognizable result early and use real UI evidence when showing an
actual workflow. Give readable words and UI time to settle. Vary motion
weight and rhythm, and plan picture and music together. Keep copy short
and specific, with one clear call to action.

For a transcription illustration, animate audio activity becoming words;
use descriptive example text and retain the completed transcript. Keep
production disclaimers out of the film; document provenance in project notes.

Use the available renderer/editor. Remotion is a good default when starting
from code. Avoid unnecessary changes to the desktop app. Use traceable assets
and synthetic demo content. Preserve actual product behavior and distinguish
editorial time skips from real processing speed.

Choose an instrumental cue with energy suited to this launch, verify its license,
edit it to the story, and mix it with clean fades. Keep the film readable
with sound off, and include the soundtrack in the exported file. Follow the
skill's music reference for sourcing, mixing, and audio verification.

Inspect style frames and a short transition proof, then the finished export. Deliver the
MP4, editable source, render command, and relevant subtitle/credit files.
State actual limitations plainly if rendering or audio is unavailable.
```

## Suggested 30-second product introduction

A proposed creative structure, not a researched optimum or approved final script. Adjust the payoff and evidence for a feature launch.

| Time | Purpose | Possible copy | Visual proof / direction |
| --- | --- | --- | --- |
| 0–3 s | Relevance | “Keep the conversation.” | Start on readable meeting notes with Loofah identity present; subtle forest framing. |
| 3–8 s | Establish product | “Record on your Mac.” | Real recording interaction, if footage exists; actual control and resulting state. |
| 8–16 s | Main payoff | “Transcribe on your Mac.” | Actual transcript with a legible excerpt; clear editorial cut if processing is skipped. |
| 16–23 s | Ownership | “Keep notes as Markdown.” | Real note and, if captured, its corresponding vault file; show the relationship simply. |
| 23–26 s | Reinforce choice | “Free. Open source.” | Calm product/identity composition. Omit if the central proof needs more room. |
| 26–30 s | Next action | “Download free for macOS” / “loofah.io” | Stable forest end card, canonical icon and wordmark; readable for several seconds. |

If suitable app footage is unavailable, use verified stills or conceptual illustration that supports current product behavior. Do not invent real app controls, fake inference results, or benchmark claims. An animated waveform becoming text is a valid explanatory device and does not need a production disclaimer. If music is unavailable after a focused search, label the delivered file as a silent draft and explain what is missing in the handoff.

For 15 seconds, retain the opening, one proof, and CTA. For longer films, add useful evidence or human context. Reframe vertical versions around a readable detail instead of scaling down a landscape desktop window.
