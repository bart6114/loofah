---

## Fixes

- Buttons, note navigation, settings, and playback controls respond more
  promptly. Transcript playback highlighting and background updates do less
  work while you interact with the app.
- Live Whisper transcription keeps speech processing from blocking other app
  work and limits queued audio when transcription falls behind.
- Whisper transcription after recording handles speech windows more efficiently
  and preserves the model's segment timing for more accurate timestamps.
- Whisper confirms the meeting language across microphone and system audio,
  with fewer repeated language checks during a meeting.
- Meetings default to English when no spoken language has been selected.

## Changes

- Retired Argmax and Qwen transcription models are no longer available.
  Existing selections move to Soniqo Parakeet Batch. Check Settings >
  Transcription to download it or select another supported model.
- Apple Reminders integration has been removed. Loofah no longer requests
  access to Reminders; existing reminders are left in Apple Reminders.
- Custom dictionary terms and automatic hints from note titles and content are
  no longer supplied to transcription. Session tags remain available, and
  existing notes, transcripts, and recordings are preserved.
