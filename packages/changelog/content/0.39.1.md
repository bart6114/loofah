---

## New

- Session summaries now live in a plain Markdown `summary.md` file inside each
  session folder, making them easier to find and edit with other tools. Existing
  summaries migrate automatically, preserving task completion and keeping the
  original documents in recoverable trash.
- **CLI:** `loof sessions export` now supports PDF, plain text, and Org alongside
  Markdown and JSON. Use `--include note,summary,transcript` to choose the content
  to export. PDF, plain text, and Org include the note and summary by default.
  PDF exports require `--output FILE` and include supported images from note
  attachments.

## Fixes

- Summary generation now protects edits made while the AI is working. If the
  summary changes before generation finishes, the generated text will not
  overwrite those edits.
