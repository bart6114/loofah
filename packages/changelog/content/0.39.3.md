## Fixes

- Loofah releases unused recording, task, summary, window and image-preview data
  more reliably, reducing memory growth during repeated use.
- Opening Note or Summary no longer loads the full transcript. Transcripts load
  when needed, with loading feedback and a retry option if reading fails.
- Tasks keep their completion state, due dates and identity when notes are closed,
  reopened or displayed in a separate window. Reopening a note no longer creates
  duplicate tasks.
- Completed recordings release their live transcript data after it is saved.
  Failed writes remain available for retry, and resumed recordings keep their
  transcript data protected during finalization.
- Completed summaries remain visible while their saved content loads. Reopening
  an existing summary does not regenerate it just because older AI history was
  cleared.
- Removing a failed image upload releases its preview, while retrying keeps the
  preview available until the upload finishes or is removed.
- CLI: task updates and moves no longer fail with a missing-session error when
  they overlap a session metadata write.
