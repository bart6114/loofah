## New

- Connect your ChatGPT account in Settings > Intelligence to generate summaries
  using your account's Codex allowance, with no API key required. This beta
  integration uses an installed Codex CLI and shows installation or update
  guidance only when needed. Sign-in opens your browser and makes summaries
  available as soon as you connect.
- Generate a summary directly from the Summary tab, even when a note has no
  recording or transcript. Use the default template or choose another before
  generating. Add some notes or a transcript to get started.
- Intelligence settings now distinguish the active provider from other configured
  providers. Use the provider and model selectors under "Model being used" to
  choose which one generates your summaries.
