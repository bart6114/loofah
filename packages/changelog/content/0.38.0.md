## New

- **About Loofah → Storage** shows your vault's total file size, file counts,
  and a breakdown by MP3, WAV, images, PDFs, JSON, Markdown, and other files.
  Categories appear largest first, with their share of the total.
- Trash is shown separately as part of the total, so it is counted only once.
  Attachments and hidden files are included. The info tooltip explains how file
  sizes can differ from space used on your Mac.
- Refresh updates the measurement while keeping the previous results visible.
  If some files cannot be measured, the screen clearly marks the result as
  incomplete.
