date: "2026-09-11"
summary: "Version 0.36.1 replaces summary templates with one editable prompt and keeps recordings until you delete them."
---

## New

- Edit one shared summary prompt in Settings > Intelligence > Summary prompt,
  or choose Edit summary prompt from a summary's menu. Save instructions for
  future summaries and regeneration, insert the current date or language, and
  reset to the bundled default at any time. Your existing custom Auto prompt
  carries over.
- Each session now uses one Summary. Older additional summaries remain available
  to read, edit, and regenerate, and regeneration keeps their titles. Existing
  text changes only when you regenerate it. The Templates library and pickers
  have been removed; old template definitions are recoverable from
  `.trash/<date>/templates/` in your vault.
- Recordings are now kept until you explicitly delete them. The audio-retention
  setting and automatic recording deletion have been removed, including deletion
  after transcription.
- Vault selection now uses the folder picker. Automatic Obsidian-vault detection
  and its shortcuts have been removed from onboarding and storage settings.

## Fixes

- Regenerated summaries now show the newly saved text immediately, including
  when regenerating an edited summary or an older template output.
- Concurrent requests to generate a summary reuse the same document instead of
  creating duplicates.
