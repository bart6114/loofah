## Recording and notes

- Record and Resume open **Note**, where you can keep typing and adding images while a meeting is recorded or processed.
- **Summary** stays readable but becomes read-only during recording, transcription, and summary generation. Editing returns when processing finishes. Keep personal text and images in Note: generating a new summary replaces earlier summary edits.
- Live transcripts follow new text more reliably, including when partial words are revised or the window changes size. Scrolling up pauses following, including across recording restarts; returning to the bottom resumes it.
- Stopping a Whisper batch transcription also cancels its background recognition work.

## Windows preview

Loofah is also available as a separate Windows 11 preview for Intel/AMD x64 and ARM64 PCs, with microphone and system-audio recording, Markdown notes, audio imports, and local transcription using Parakeet or Whisper. Speaker detection, floating recording controls, live captions, and meeting reminders are included.

The Windows preview is unsigned while publisher verification is pending. Windows may show an unknown-publisher warning, and managed PCs may block installation. Physical-device testing is ongoing. Earlier ARM virtual-machine tests returned an empty Whisper transcript; Parakeet is an alternative to try. The macOS download remains signed and notarized.

## CLI and agent access

- Windows users can install the bundled `loof` command from **Settings → Agents** and connect MCP clients to their local vault.
- Notes and transcripts use the same vault format on macOS and Windows.
