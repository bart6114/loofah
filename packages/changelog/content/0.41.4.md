## Fixes

- The current user now appears as "You" instead of an internal ID in transcripts and copied or exported transcript text when no display name is available.
- Local Whisper transcription now accepts requests up to 250 MiB, increased from 100 MiB. This addresses the "length limit exceeded" error for recordings that exceeded the previous limit.
- Transcription settings show the selected model's supported languages and warn when your meeting languages are unsupported. Transcription keeps your selected model instead of silently switching to another one.
- Images and attachments can be dragged to a different position within a note on macOS. These moves support undo, and dropping files from Finder still works.
- CLI: `loof transcribe` checks whether the selected transcription model is downloaded, rather than requiring a different batch model.
