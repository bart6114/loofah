## New

- Desktop, CLI, and MCP now share a search cache for each vault. Desktop rebuilds it automatically after updating; CLI and MCP create a missing or incompatible cache on first use, with progress on stderr.
- CLI: `loof init` builds, refreshes, or repairs the cache explicitly. With `--json`, it streams NDJSON progress on stderr and returns the final response on stdout.

## Changed

- CLI and MCP search refresh external edits before querying and use desktop word, phrase, and prefix matching. Results contain one relevance-ranked hit per session, with its ID, score, and snippets. List queries now use full-text matching and relevance order.
- CLI compatibility: JSON responses use schema version 2. Search requires a query; CLI `--speaker`/`--kind` and MCP `speaker`/`kinds` filters are removed. Fetch full transcripts separately for speaker and timing details.
- CLI writes reconcile affected sessions before reporting success. A `write_persisted` error means the write was saved; repair or refresh the cache without repeating the write.
