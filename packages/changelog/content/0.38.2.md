date: "2026-09-18"
summary: "Version 0.38.2 adds recoverable session deletion to the CLI and makes deleting notes safer."
---

## New

- **CLI:** `loof sessions delete <ID>` moves a session's entire folder, including
  recordings and attachments, into recoverable vault trash. The exact session ID
  confirms deletion, so the command does not prompt.
- **CLI:** Add `--json` to receive the deleted session's ID and exact trash path
  for scripts and agents. Missing or already-deleted sessions return `not_found`
  with exit code 2.

## Fixes

- If a note cannot be moved to the vault's trash, pending transcript changes are
  preserved.
- Moving notes to the vault's trash now protects existing trashed files from
  being overwritten, even when deletions happen at the same time.
