## Windows preview

Loofah now has native Windows 11 builds for Intel/AMD x64 and ARM64 PCs. Record your microphone and system audio, take Markdown notes, import recordings, and generate summaries with local or API-key providers.

- Transcribe locally with Parakeet or Whisper. Parakeet supports live English transcription and batch transcription in 25 European languages. Whisper supports live and batch transcription, using Vulkan when available with a CPU fallback.
- Add speaker labels after recording or importing audio. Download speech and speaker models before going offline.
- Use floating recording controls, live captions, meeting reminders, Windows shortcuts, and launch-at-login settings.
- **CLI and MCP:** Install the bundled `loof` command from Settings → Agents. Keep your existing vault format and connect your agent clients on Windows.

The Windows preview is unsigned while publisher verification is pending. Windows may show an unknown-publisher warning, and managed PCs may block installation. In-app updates are cryptographically verified. Physical-device testing is ongoing; please report problems with your app version, processor, and selected model. Earlier ARM virtual-machine tests returned an empty Whisper transcript; Parakeet is an alternative to try.

Nemotron and Omnilingual remain specific to macOS. The macOS app continues to use its existing signed download.
