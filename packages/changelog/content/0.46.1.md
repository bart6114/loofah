## Dictation

Start speaking before choosing where your words should go. When transcription finishes, Loofah tries to insert the text at your current cursor or selection, including if you switched fields while speaking. If insertion is unavailable, your words remain available to copy.

## Permissions and controls

- Enabling dictation on macOS requests Accessibility access for automatic insertion. If access was previously denied, enabling it again opens Accessibility settings. You can still dictate and copy without Accessibility access when Input Monitoring is enabled.
- Dictation's audio meter now makes quiet speech easier to see and settles smoothly during silence.
- Messages such as **No speech detected** now have a visible **Dismiss** button alongside the other controls.
- Dictation settings have clearer spacing and no longer ask for a separate Input Monitoring grant when Accessibility already allows the shortcut.
