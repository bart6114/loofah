---
title: "Markdown meeting notes and your local vault"
description: "Keep meeting notes and summaries as Markdown in your local vault. Search sessions, export documents, and save research through the Loofah CLI."
---

Your notes and AI summary documents are stored as Markdown files in your local vault. Transcripts use structured JSON, and the recording and attachments are stored alongside the session. Export a complete session when you want its transcript included in a Markdown document.

The vault is not limited to recorded meetings. Every entry is a **session**, and a session can be a standalone note or a meeting with a recording and transcript. Use sessions for research, project context, decisions, reference material, or anything else you want to keep locally and find again.

A session can contain:

- **Memos** you or an authorized agent write.
- **Summary** documents generated by the configured Intelligence model.
- **Transcript** text from a recording or imported subtitle file.
- **Attachments** referenced from the memo.

Memos and summaries are editable. In the transcript, click a speaker label to assign or change the speaker.

## Create a standalone note

Choose **New Note** and start writing. You do not need to record audio or add a transcript. The note is stored as a session, so it appears in the same timeline and search results as meeting notes.

Agents can create the same kind of note through the CLI. This makes it practical to bring in material from any tool the agent is authorized and able to read: the agent turns the useful result into Markdown, records its authorship, and creates a session in the vault.

```bash
loof --json sessions new \
  --title "Research: local speech models" \
  --note research.md \
  --tag research \
  --author claude-code \
  --skill research-assistant
```

The CLI does not connect to or scrape those source tools itself. The agent supplies the Markdown through a file or stdin. If the original deck, report, or other artifact should travel with the note, the agent can add it with `sessions attach`.

:::note
You can also edit the memo from the terminal: `loof sessions note ID --set FILE` replaces it, and `--append` adds to it. See the [CLI reference](/reference/cli).
:::

## Change the summary format

Choose **Edit summary prompt** from the Summary menu to open **Settings → Intelligence → Summary prompt**. Save your changes, then regenerate a summary to apply them. All new summaries use this shared prompt.

See [Customize meeting summaries](/customize-summaries) for the shared prompt and dictionary terms.

## Export a session

1. Open the **•••** menu in the meeting header.
2. Choose **Export**.
3. Select PDF, text, Markdown, or Org.
4. Choose whether to include the memo, summary, transcript, or any combination of them.

The app writes the file to Downloads and reveals it in Finder.

## Keep your files useful elsewhere

You can read Markdown notes with another editor and back up the vault with your own tools. To use the same vault across Macs, choose a [supported local sync folder](/syncing). Syncing is provided by the service you configure, so consider its data policy.

For agents, use [read-only MCP access](/agents/connect-clients) to retrieve context and the [CLI](/agents/cli) to save work. Agents should use these interfaces instead of modifying the vault’s internal files.
