---
title: Customize meeting summaries
description: "Edit the shared prompt used for every summary."
---

Summary generation is optional. When Intelligence is configured, every summary uses one shared prompt for your vault.

## Edit the summary prompt

1. Open **Settings → Intelligence → Summary prompt**, or choose **Edit summary prompt** from a summary's menu.
2. Edit the prompt and click **Save**.
3. Regenerate an existing summary to apply your changes to it.

Saved changes apply to future generation, including automatic summaries and regeneration of older summaries. Existing text stays as it is until you regenerate it. Regeneration preserves the document's title.

The **Current date** and **Language** buttons insert variables that are filled in when the prompt runs. Invalid syntax and unsupported variables must be corrected before saving. Use **Reset to default** to restore the bundled prompt.

Loofah supplies notes, transcripts, session details, participants, and supported note images separately. Your prompt can choose its own format; the summary-length policy still applies.

Each session gets one Summary. Older additional summaries remain available to read, edit, and regenerate.

## Older templates

Your previous custom Auto prompt carries over automatically. Saved summary documents are preserved. Old template definitions are archived under `.trash/<date>/templates/` in your vault, where you can recover their text with Finder. They are no longer active templates.

## Add names and jargon

Open **Settings → Dictionary** to add names, acronyms, product names, and other terms that transcription often misses.

Dictionary terms help recognition, but they do not change which spoken languages a model supports. See [Languages](/languages) when a meeting uses more than one language.
