## iPhone app

The iPhone app records microphone audio. Download a transcription model in **Settings → Transcription** before transcribing a recording. Your notes and recordings start in a private local vault; connecting an iCloud Drive vault is optional. See [Data, privacy, and retention](/data-and-privacy) for details.

If the app is not behaving as described, try [Troubleshooting](/troubleshooting). For help with the iPhone app or to report a problem, email [hi@barts.space](mailto:hi@barts.space) or [open a GitHub issue](https://github.com/bart6114/loofah/issues).
